Escape does not close the "Set icon" emoji picker

## Steps to reproduce
1. New Space → Options → Image → Icon (or Customize → Set icon on a space).
2. Press Escape (twice).

## Actual
The picker stays open; the first Escape only blurs its search field (focus moves to `<body>`). Only X closes it.

## Expected
Escape closes the topmost modal (as the crop modal does).

## Cause (web v8.1.0)
`SpaceImagePicker.vue:47` and `useSpaceActionsSetIcon.ts:41` use `focusTrapInitial: false`; emoji-mart autofocuses its search (`OcEmojiPicker.vue:87`) and handles Escape itself; `OcModal.vue:14` only listens on the dialog.

## Fix idea
Keep focus inside the dialog or listen for Escape on the document while the modal is active.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), margaret, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H5-C1, reproduced 2/2 (both entry points).
