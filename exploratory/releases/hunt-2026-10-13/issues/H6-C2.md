Delete from the editor with unsaved changes: file deleted first, then Save fails with a misleading message

## Steps to reproduce
1. Open a `.md` in the Text Editor and type (unsaved).
2. Top bar ⋮ → Delete; in "Unsaved changes" click Save.

## Actual
The file is already in the trash when the dialog appears; Save → 412 → "This file was updated outside this window…"; the editor stays open on a deleted, dirty file.

## Expected
Warn before deleting a dirty file, or close without offering an impossible save; the error should say the file was deleted.

## Cause (web v8.1.0)
`AppWrapper.vue:765-767,893-895` delete without checking `isDirty`; `737-751` then closes the app and `819-843` offers Save; `573-578` treats every 409/412 as an external update.

## Fix idea
Check `isDirty` before deleting (confirm), and skip the save prompt after a delete.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), alan, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H6-C2, reproduced 2/2.
