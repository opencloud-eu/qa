Tag filter returns wrong results for a tag containing "+"

## Steps to reproduce
1. Tag file A with `x+y` and file B with `x`.
2. Results page → Tags filter → select `x+y`; reload.

## Actual
Only file B (tag `x`) is listed; the chip shows `x`. The server answers `tag:"x+y"` correctly.

## Expected
Only file A, chip `x+y`.

## Cause (web v8.1.0)
Values are joined/split on an unescaped `+` (`packages/web-pkg/src/components/ItemFilter.vue:139-152,225`; `packages/web-pkg/src/composables/search/useSearch.ts:129`).

## Fix idea
Encode each value or use repeated query params.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), alan, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H7-C3, reproduced 2/2.
