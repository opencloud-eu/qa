Search location filter ("Current folder"/"All files") does not follow the URL on Back/Forward

## Steps to reproduce
1. In a subfolder search with "All files", then switch to "Current folder".
2. Press Back.

## Actual
URL `useScope=false` and all results, but the chip still shows "Current folder"; the next search uses the chip state.

## Expected
Chip shows "All files".

## Cause (web v8.1.0)
`packages/web-pkg/src/components/SearchBarFilter.vue:93-133` doesn't watch the `useScope` query; `SearchBar.vue:180,351` only changes it on user input.

## Fix idea
Watch the `useScope` route query.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), alan, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H7-C4, reproduced 2/2.

Screenshots: `screens/H7-C4-H7-10-loc-after-back-run1.png` in the hunt folder.
