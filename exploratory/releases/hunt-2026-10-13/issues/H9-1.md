"Mark all as read" clears the notification list even when the request fails

## Steps to reproduce
1. Have notifications in the bell.
2. Click "Mark all as read" while the DELETE request fails (network / server error).
3. Reload.

## Actual
The list shows "Nothing new", no error; after reload all notifications are back.

## Expected
Error message; notifications stay.

## Cause (web v8.1.0)
`packages/web-runtime/src/components/Topbar/Notifications.vue` `deleteNotificationsTask` filters the list in `finally` and only logs errors.

## Fix idea
Filter only on success and show an error message.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), alan, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H9-1, reproduced 1/1 (explorer).
