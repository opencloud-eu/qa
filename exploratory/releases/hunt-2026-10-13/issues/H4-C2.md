Public link can be renamed to a whitespace-only name

## Steps to reproduce
1. Sidebar → Share → link ⋮ → Rename.
2. Enter three spaces and save.

## Actual
"Link was updated successfully"; the server stores `"   "`; the row shows no name.

## Expected
Validation error as for an empty name, or trimming.

## Cause (web v8.1.0)
`packages/web-app-files/src/components/SideBar/Shares/Links/EditDropdown.vue:177-185` checks `name.length` without trim.

## Fix idea
Validate `name.trim()` and send the trimmed value.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), alan, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H4-C2, reproduced 2/2.
