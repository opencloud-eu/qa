Version check hidden and console TypeError on edition `dev`

### Steps
1. Run a dev build (`opencloudeu/opencloud:dev`, status.php `9.0.0+dev`, edition `dev`).
2. Log in, look at the sidebar footer or Admin → General; open the browser console.

### Expected
"Up to date" / "Version X available" under the version, or the check is skipped silently for editions without an
update channel.

### Actual
The version check is not shown. Every page logs
`TypeError: Cannot read properties of undefined (reading 'current_version')`.

### Cause
`https://update.opencloud.eu/server.json` has the channels `rolling, stable, lts, lts-2.0, lts-4.0`, but no `dev`.
`packages/web-pkg/src/components/VersionCheck.vue` reads `updates.channels[serverEdition].current_version` without a guard.

### Note
Release builds (`rolling`, `stable`) are not affected. Low severity: console noise only.

Found by the agent-driven upgrade test 8.1.0 → 9.0.0-dev.
