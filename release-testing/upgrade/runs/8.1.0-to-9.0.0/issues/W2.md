"Shared with me" footer counts hidden shares

### Steps
1. User B has received several shares and has hidden one of them.
2. Log in as B → Shares → Shared with me (default filter, hidden shares not shown).

### Expected
The footer matches the listed items (e.g. 9 tiles → "9 items").

### Actual
The footer counts the hidden share too: 9 tiles, footer "10 items with 5 kB in total (6 files, 4 folders)";
for a second user 6 tiles, footer "7 items … (0 files, 7 folders)".

### Note
Seen on web 8.2.0 (opencloud dev). Not compared with 8.1.0, so it may be older behaviour. Minor, cosmetic.

Found by the agent-driven upgrade test 8.1.0 → 9.0.0-dev.
