After upgrading to 8.1.0, users who disabled notification mails see mail as enabled and cannot switch it off

### Steps
1. OpenCloud 7.5.0: Account → Preferences, untick "Receive notification mails" (`disable-email-notifications=true`).
2. Upgrade to 8.1.0.
3. Account → Preferences.

### Expected
The page shows that notification mails are off, and the user can change it.

### Actual
- The global "Receive notification mails" checkbox is gone, because 8.1.0 enables per-event notification settings by
  default (`FRONTEND_CONFIGURABLE_NOTIFICATIONS=true`).
- The per-event table shows every Mail box ticked.
- The server still has `disable-email-notifications=true`, and `disableEmails()` still suppresses all mails, so the
  user gets no mail while the page says mail is on. There is no control left to turn the global setting back.

### Components
web (preferences page) and opencloud (new default).

Found by the agent-driven upgrade test 7.5.0 → 8.1.0.
