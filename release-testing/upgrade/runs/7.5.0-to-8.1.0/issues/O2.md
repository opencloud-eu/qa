Graph: `PATCH {name}` on a received share returns 200 but does not rename, and unhides a hidden share

### Steps
1. User B received a share; optionally B hid it (`@UI.Hidden: true`).
2. B: `PATCH /graph/v1beta1/drives/{sharesJail}/items/{id}` with `{"name":"new-name"}`.

### Expected
The share is renamed for B (or a 400 if renaming is not supported), and the hidden state is unchanged.

### Actual
HTTP 200, the name does not change (`UpdateDriveItem` only applies `@UI.Hidden`). A body without `@UI.Hidden` also
unhides a hidden share. Renaming works via WebDAV `MOVE`. Same on 7.5.0 and 8.1.0.

Found by the agent-driven upgrade test 7.5.0 → 8.1.0.
