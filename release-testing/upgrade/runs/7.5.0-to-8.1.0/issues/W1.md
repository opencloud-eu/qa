Edit user panel shows "No restriction" for a quota that is not one of the presets

### Steps
1. As admin, set a user's personal quota to 1 GiB via Graph (`PATCH /graph/v1.0/drives/{id}` `{"quota":{"total":1073741824}}`).
2. Admin settings → Users → select the user → Edit.

### Expected
Personal quota shows 1 GiB (or the exact value).

### Actual
"Personal quota: No restriction". The details panel and the API show 1 GiB; saving the panel keeps the quota, so only
the display is wrong — but an admin may think the user has no limit. Presets (e.g. 1 GB = 1000000000 bytes) show
correctly. Reproduced on users created on 7.5.0 and on 8.1.0.

Found by the agent-driven upgrade test 7.5.0 → 8.1.0 (web 8.1.0).
