Console error `Cannot read properties of undefined (reading 'replaceAll')` when opening the share panel of an item with an internal link

### Steps
1. Create an internal link on a file.
2. Open the file's sharing panel in the right sidebar.

### Expected
No console errors.

### Actual
`TypeError: Cannot read properties of undefined (reading 'replaceAll')` inside `gettext`, every time. The panel still
renders correctly. Reproduced on items created on 8.1.0.

Found by the agent-driven upgrade test 7.5.0 → 8.1.0 (web 8.1.0).
