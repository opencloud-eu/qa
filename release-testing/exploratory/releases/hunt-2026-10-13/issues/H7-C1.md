Search results page spins forever when Enter is pressed during the preview debounce and the search is slow

## Steps to reproduce
1. Type a term in the top-bar search and press Enter within 500 ms.
2. The search request takes > ~0.5 s (simulated 1 s delay).

## Actual
The preview REPORT aborts the list REPORT (`net::ERR_ABORTED`); the results page shows the spinner forever. Also when clicking into the search bar while the list search runs.

## Expected
The results are shown.

## Cause (web v8.1.0)
Preview and list share one restartable task (`packages/web-app-files/src/extensions.ts:41`, `useSearch.ts:38-86`); `packages/web-app-search/src/views/List.vue:37-40` returns on cancel without resetting `loading`; `SearchBar.vue:306-313` cancels the debounce only when already on the results page.

## Fix idea
Separate tasks for preview and list, cancel the debounced preview on Enter, reset `loading` on cancel.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), alan, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H7-C1, reproduced 2/2 (+1/1 click variant).
