Enter in "Edit password" submits an empty/too short password although Confirm is disabled

## Steps to reproduce
1. Sidebar → Share → link ⋮ → Edit password.
2. Leave the field empty (or 2 chars) and press Enter.

## Actual
`setPassword {"password":""}` is sent. Here the server rejects it (password enforced). Without enforcement this would probably remove the link password silently (not verified).

## Expected
Nothing is submitted while Confirm is disabled.

## Cause (web v8.1.0)
`packages/web-app-files/src/components/Modals/SetLinkPasswordModal.vue:62-67` emits confirm on Enter unconditionally; `packages/web-runtime/src/components/ModalWrapper.vue:74-93` doesn't check `confirmDisabled`.

## Fix idea
Guard Enter / `onModalConfirm` on `confirmDisabled`.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), alan, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H4-C3, reproduced 2/2.
