App token note accepts whitespace only

## Steps to reproduce
1. App Tokens → New, note = three spaces, any date.

## Actual
Confirm is enabled; the token would get a blank note.

## Expected
"The note is required" / Confirm disabled.

## Cause (web v8.1.0)
`AppTokenModal.vue` `isConfirmDisabled` uses `!tokenLabel` without trim.

## Fix idea
Trim before validating.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), alan, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H9-4, reproduced 1/1 (explorer, checked via isDisabled).
