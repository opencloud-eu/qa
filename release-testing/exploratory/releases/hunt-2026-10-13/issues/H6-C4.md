Video opened from the file list never autoplays although the preview app intends to

## Steps to reproduce
1. Upload a `.webm` and click it in the file list.

## Actual
`<video autoplay>` is false, the video is paused.

## Expected
Autoplay for the first item (`isAutoPlayEnabled` starts as true).

## Cause (web v8.1.0)
`packages/web-app-preview/src/App.vue:468-482` — the watcher is not immediate, `oldValue` is `undefined` on the first run and `oldValue !== null` switches autoplay off.

## Fix idea
Use `oldValue != null`.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), alan, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H6-C4, reproduced 2/2.

Screenshots: `screens/H6-C4-H6-video.png` in the hunt folder.
