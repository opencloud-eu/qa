A failed drag & drop move shows no error (e.g. locked file → 423)

## Steps to reproduce
1. Lock a file (open in Collabora, or WebDAV `LOCK`).
2. Drag it onto a folder in the file list.

## Actual
The server answers `MOVE` with 423 (or any 5xx); the UI shows nothing, the file just stays. Cut + paste of the same file shows "Failed to move …".

## Expected
An error message as for cut/paste, or dragging locked files is not allowed (Move-to is hidden for locked files).

## Cause (web v8.1.0)
`packages/web-app-files/src/views/spaces/GenericSpace.vue:502-505` — the `startWorker` callback of `fileDropped` ignores `failed` and never calls `resourceTransfer.showResultMessage`; no `locked` guard like `useFileActionsMove.ts:227`.

## Fix idea
Call `showResultMessage(failed, successful, …)` in the drop callback and skip locked resources.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), alan, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H1-C2, reproduced 2/2 (423 real, 500 mocked).
