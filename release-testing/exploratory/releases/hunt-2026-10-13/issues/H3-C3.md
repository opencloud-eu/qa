Shared with me: item disappears live when one of two shares is removed although access remains via group

## Steps to reproduce
1. alan shares a file with lynn directly and with a group lynn is in.
2. lynn has Shared with me open.
3. alan removes only the direct share.

## Actual
The file vanishes from lynn's list immediately (SSE `share-removed`); the server still lists it and a reload shows it again.

## Expected
The file stays in the list.

## Cause (web v8.1.0)
`packages/web-runtime/src/container/sse/shares.ts:300-306` removes the resource by `fileId` without checking for other shares on the item.

## Fix idea
Re-fetch `listSharedWithMe` (as `onSSEShareCreatedEvent` does) instead of removing blindly.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), alan, lynn, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H3-C3, reproduced 2/2.
