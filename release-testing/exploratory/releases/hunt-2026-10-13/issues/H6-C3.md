Text editor and preview open any resource type from a deep link (folder, PNG as editable text, wrong file in preview)

## Steps to reproduce
1. Open `/text-editor/…/<folder>?fileId=<folder id>`, `/text-editor/…/<image>.png?fileId=<png id>`, `/preview/…/<doc>.md?fileId=<md id>`.

## Actual
Folder → blank editor with Save; PNG → binary shown as editable text (saving would overwrite the image); `.md` in preview shows the first image of the folder under the md title.

## Expected
"This file type cannot be opened with <app>" or redirect to the default app.

## Cause (web v8.1.0)
`AppWrapper.vue:413-465` (`loadFileTask`) never checks resource type / mime against the app; `web-app-preview/src/App.vue:417-431` falls back to index 0.

## Fix idea
Validate that the resource is a file with a mime type registered for the app.

## Environment
OpenCloud 8.1.0+85466427 (rolling), web 8.1.0, Chromium (Playwright), alan, desktop. Found in the exploratory bug hunt of 2026-10-13 (opencloud-eu/qa, `exploratory/releases/hunt-2026-10-13`), finding H6-C3, reproduced 1/1 (explorer).
