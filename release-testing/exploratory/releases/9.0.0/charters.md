- Instance: https://cloud.opencloud.test, productversion `9.0.0+dev` (edition `dev`; the release build will report a
  release edition). It is the stack of the upgrade test 8.1.0 → 9.0.0 (`release-testing/upgrade/runs/8.1.0-to-9.0.0`),
  so it holds `qa-up-*` test data.
- Optional features: Collabora (odt/ods/odp in "New") **found** · full-text search (Tika) **found** · App Store (admin)
  **found** · guest links (`OC_ENABLE_GUEST_LINKS=true`) **found** · mail (notifications service → inbucket,
  http://localhost:9000) **found** · vault (encrypted folder via New → Folder) **found** · Excalidraw **not found** ·
  OnlyOffice / EuroOffice **not found** · federation (OCM) **off** · public links: password enforced for all types.
- Already covered by the upgrade test (API level, see its report): thumbnails of old files (#3397), guest-link backend
  flow (#3609), share migration, default quota capability, search on the old index. Known there: F1 (guest on a whole
  project space), T1 (truncated PNG preview 500), W1 (`current_version` TypeError on edition dev), W2 ("Shared with me"
  footer counts hidden shares), U1 (unread notifications lost on restart).
