New notification mails: long file names without spaces break the layout

### Steps
1. Share a file with a long name without spaces (e.g. 150 × `x` plus unicode) with a user.
2. Open the "shared with you" (or "unshared") mail, also at phone width (400 px).

### Expected
The name wraps inside the card; button and link stay visible.

### Actual
The name does not wrap: heading and text run out of the card, the card is stretched, the footer is off-centre.
At 400 px the mail is 1817 px wide and the button and link are cut off. Mails with normal names look correct.

### Note
New mail design (opencloud#3789) on 9.0.0+dev. Reproduced with two mail types, each rendered three ways (raw HTML,
inbucket web view, 400 px). Fix idea: `overflow-wrap: anywhere` / `word-break: break-word` on headings and text.

Found by the agent-driven exploratory test of OpenCloud 9.0.0.
