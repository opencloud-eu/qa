"Keep both" puts " (1)" after the last dot of names without an extension

### Steps
1. In a folder, have a file `release 1.2 notes` (a dot, but no extension).
2. Upload another file with the same name and choose "Keep both" in the conflict dialog.

### Expected
`release 1.2 notes (1)`

### Actual
`release 1 (1).2 notes`; a second upload gives `release 1 (2).2 notes`. Same for `qa-9.0.0-clash` → `qa-9.0 (1).0-clash`.
The server stores these names.

### Note
Reproduced 3 times from 2 fresh logins on 9.0.0+dev / web 8.2.0. The text after the last dot is treated as the
extension (`resolveFileNameDuplicate` in `packages/web-pkg/.../conflictUtils.ts`). Probably older behaviour, not new in 8.2.0.

Found by the agent-driven exploratory test of OpenCloud 9.0.0.
