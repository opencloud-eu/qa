Space name error message shows a double backslash and an apostrophe that is allowed

### Steps
1. As a space admin, Spaces → New → type a name with a dot, e.g. `a.b`.

### Expected
`The Space name cannot contain the following characters: / \ . : ? * " > < |`

### Actual
`The Space name cannot contain the following characters: / \\ . : ? * " > < |'` — two backslashes and a trailing
apostrophe. The check (`/[/\\.:?*"><|]/`) does not forbid `'`, so the message lists a character that is allowed.

### Cause
`packages/web-pkg/src/composables/resources/useIsResourceNameValid.ts`: the string is
`'… / \\\\ . : ? * " > < |\''` — `\\\\` renders as `\\`, `\'` adds the apostrophe.

### Note
Reproduced twice on 9.0.0+dev / web 8.2.0. Minor (text only).

Found by the agent-driven exploratory test of OpenCloud 9.0.0.
